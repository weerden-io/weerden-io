# weerden.io frontend

Angular 22 frontend for the weerden.io website.

## Commands

- `yarn serve` starts the dev server on http://localhost:4200
- `yarn build-prod` creates the production build in `dist/weerden-io/browser`
- `yarn test` runs the unit tests with Vitest
- `yarn lint` runs ESLint
- `yarn e2e` runs the Cypress end to end tests against a running dev server
- `yarn e2e-ci` starts the dev server and runs the Cypress tests against it

## Requirements

Node.js ^22.22.3 or ^24.15.0 and yarn 1.x.
